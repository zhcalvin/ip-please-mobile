# 揪起你的盖头来 · 微信小游戏客户端

在仓库根目录运行 `node wechat/tools/build.mjs`，用微信开发者工具导入 `wechat/minigame/`，项目类型选择**小游戏**。项目已填写 AppID `wx2484d6db995ed6b2`，请用该项目开发者账号登录。生成目录无需提交。

`minigame/config.js` 仅包含公开 API 地址 `https://api.momoyu.ltd`。小游戏后台的服务器域名中需添加该 HTTPS request 域名；AppSecret 只保存在服务器端。

该版本原生使用微信 Canvas 2D，不嵌套网页。构建时按原顺序将游戏脚本放在同一个作用域，并把内嵌图片提取为本地 PNG。六天剧情、询问、测谎、拘留、快剪和蒸馏大军均沿用原版。音效使用微信 WebAudio；兼容同步生命周期接口和不返回目标节点的 `connect`。不支持音频的客户端仍可静音游玩。

标题、每日结算和结局左上角可打开全国榜，支持前 20 名翻页、刷新和个人最佳。按每日扣除家庭开销后最高剩余 Token 排名。排行榜仅使用匿名审查员编号，不申请头像、昵称或地理位置权限。

从头开始时先微信登录并向服务器申请带随机种子的对局，成功后才开始计分。登录、域名或服务不可用时自动转为练习，离线完整游戏仍可玩。继续存档只有与本机原有在线对局的每日边界快照完全一致时才计分；普通网页或旧练习存档无法自动变成排名成绩。

每日决策和支出记录在本机保存，网络恢复或再次打开时补交；服务器重算分数，逐日重复提交幂等。未结算的一天被中断后从当天开始重新进行。历史最佳不会因第六天的剧情清零而消失。此方案验证合法事件与算分，不保证防止自动化或修改客户端后进行合法的完美操作。

验证命令：`node --test wechat/tests/client*.test.mjs`。Node 模拟测试不能代替微信真机对音频、横屏安全区、触摸和前后台的验收。
